# Frozen U1 MobileNetV2: Final Held-out TEST

**Test evaluation:** One planned pass on 5,271 official held-out ultrasound images from 896 unseen patient groups.

- TEST accuracy: **85.4297%**
- TEST macro-precision: **0.818983**
- TEST macro-recall: **0.860314**
- TEST macro-F1: **0.834528**
- TEST correct: **4503/5271**
- Model: frozen U1 MobileNetV2 selected based on earlier validation comparisons.
- Original test images were not used to select, train, or tune the model.
- Test and historical validation metrics must be presented separately.

This is not an external-hospital study or a clinically validated diagnostic tool.
Softmax scores should not be interpreted as calibrated clinical confidence.
